# Classic Russian Translation: Универсальный Кодекс для ИИ-агентов

**Фундаментальная методология воссоздания мировой художественной классики на русском языке (школа Норы Галь, Корнея Чуковского, Михаила Лозинского).**

---

## О проекте

Современные большие языковые модели обладают колоссальным словарным запасом и способны превзойти конвейерный коммерческий перевод, если освободить их от корпоративной стерильности и направить по канонам золотого фонда отечественной школы художественного перевода.

В этом репозитории содержится единственный эталонный файл правил:
* **[`AGENTS.md`](AGENTS.md)** — универсальный кодекс для автономных ИИ-агентов (Antigravity, Cursor, Claude Code и др.).

## Как использовать

1. Положите файл `AGENTS.md` в корень рабочего пространства вашего переводческого проекта.
2. Любой агент, подключенный к проекту, автоматически примет роль суверенного писателя-переводчика и применит:
   * **Канон Норы Галь:** война с номинализацией и канцеляритом, сжатие расщепленных сказуемых в упругие глаголы действия.
   * **Канон Корнея Чуковского:** перевод стиля стилем, идиоматическая конгениальность, сохранение авторских диссонансов.
   * **Канон Михаила Лозинского:** закон полноты объема (0% купюр), полифония и уникальные речевые паспорта персонажей.
   * **Принцип эстетического хронотопа:** текст звучит на русском языке эпохи оригинала (или авторской стилизации), отсекая анахронизмы из будущего.
   * **Отказ от цензуры (Anti-Sanitization):** сохранение всей правды оригинала (брань, телесность, социальные конфликты).
   * **6-ступенчатый конвейер самоконтроля.**
